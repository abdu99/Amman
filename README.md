# AMAN (أمان)

برنامج Windows Desktop لحماية الفيديوهات بكلمة سر، وتجميعها في حزمة واحدة مشفّرة (AES-256)
تُصدَّر كملف EXE واحد قابل للتوزيع يعمل على أي جهاز ويندوز دون تثبيت أي برنامج إضافي.

مبني بـ **C# / WPF / .NET 8** (اختيار مقصود على Python+PyQt للأداء الأصلي على ويندوز، وسهولة
إنتاج ملف EXE واحد ذاتي الاكتفاء عبر `dotnet publish --self-contained -p:PublishSingleFile=true`
بدون الحاجة لتوزيع Python runtime).

## الميزات المُنفَّذة

**Encoder:**
- إضافة فيديوهات متعددة (سحب وإفلات + تصفح ملفات)، ترتيب بالسحب والإفلات
- كلمة سر واحدة تحمي كل فيديوهات الحزمة (AES-256-GCM لكل فيديو بمفتاح مستقل)
- وضعان للحماية: كلمة سر عامة، أو كلمة سر + كود تفعيل مرتبط بجهاز محدد (ECDSA)
- تصدير الحزمة كملف EXE واحد
- علامة تجارية مخصصة: عنوان، شعار، لون مميز، وضع ليلي/نهاري
- صلاحية زمنية اختيارية وعدد مرات تشغيل اختياري (على مستوى الحزمة كلها، وأيضًا لكل مستخدم عبر كود التفعيل)
- توليد أكواد التفعيل لجهاز محدد من داخل الواجهة

**Player:**
- طلب كلمة السر (وكود التفعيل إن وُجد) عند التشغيل
- قائمة تشغيل داخلية بعد الفتح، مشغّل فيديو مدمج بأزرار تحكم كاملة (تشغيل/إيقاف/تقديم/تالي/سابق/صوت/ملء الشاشة)
- لا يُكتب أي فيديو غير مشفّر على القرص إطلاقًا — فك التشفير يجري لكل قطعة عند الطلب فقط، عبر خادم بث محلي
- دعم عربي/إنجليزي كامل مع اتجاه RTL/LTR، ووضع ليلي/نهاري

**الأمان:**
- AES-256-GCM لكل فيديو، بمفاتيح مستقلة مغلَّفة بمفتاح مشتق من كلمة السر (PBKDF2 + HKDF)
- كلمة السر لا تُخزَّن أبدًا كنص صريح — فقط قيمة تحقق (verifier) غير قابلة للعكس
- صيغة حاوية مخصصة غير قابلة للفتح بأدوات ضغط/فك عادية
- توقيع ECDSA اختياري لرأس الحاوية ولأكواد التفعيل (مفتاح خاص لا يغادر جهاز البائع أبدًا)

## ملاحظة صادقة حول الحماية من التسجيل/النسخ

البند المطلوب "منع التسجيل/النسخ" نُفِّذ كـ**رادع (deterrent)** حقيقي وليس ضمانًا مطلقًا —
ولا يوجد برنامج على وجه الأرض يمكنه ضمان ذلك 100% (كاميرا هاتف موجَّهة للشاشة تتجاوز أي حماية
برمجية). ما نُفِّذ فعليًا:
- استثناء نافذة المشغّل من واجهات التقاط الشاشة القياسية في ويندوز (`SetWindowDisplayAffinity`، ويندوز 10 2004+)
- منع مفتاح Print Screen عبر hook منخفض المستوى
- منع القائمة اليمنى/السحب من منطقة الفيديو
- علامة مائية متحركة (تحمل معرّف الجهاز) لأغراض التتبّع إن سُرِّب تسجيل رغم كل ذلك

راجع التعليقات في `Aman.Player/Services/AntiCaptureService.cs` والحدود الموثّقة في
`docs/CONTAINER_FORMAT.md` و`docs/LICENSING_SYSTEM.md` لتفاصيل كاملة وصادقة حول حدود كل آلية حماية.

## حالة البناء

طُوِّر هذا المشروع في بيئة Linux بدون .NET SDK أو ويندوز متاحين، لذا **الكود لم يُبنَ أو
يُختبر فعليًا بعد**. راجع [`docs/BUILD.md`](docs/BUILD.md) للخطوات على جهاز ويندوز، وتوقّع
الحاجة لإصلاحات ترجمة (compile fixes) طفيفة محتملة عند أول بناء فعلي لمشروع بهذا الحجم.
