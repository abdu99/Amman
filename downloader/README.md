# MultiDownloader

برنامج Windows Desktop لتحميل الملفات والبرامج والفيديوهات والصوتيات — من روابط مباشرة أو من
يوتيوب وآلاف المواقع الأخرى — بواجهة واحدة.

> **مستقل تمامًا عن AMAN**: هذا مجلد منفصل داخل المستودع، لا يشارك أي كود أو واجهة مع برنامج
> حماية الفيديوهات (`src/Aman.*` في جذر المستودع). لا حاجة لبناء أو تشغيل أحدهما لاستخدام الآخر.

## الميزات

- **تنزيلات متعددة في آنٍ واحد** (قائمة انتظار): كل رابط "مشروع" مستقل — يمكن تشغيل عدة تنزيلات
  بالتوازي بحد أقصى قابل للتعديل من الإعدادات.
- **استئناف بعد التوقف**: يعمل حتى بعد إغلاق البرنامج تمامًا — يُحفظ تقدّم كل ملف على القرص.
- **الملفات المباشرة (برامج، ضغط، مستندات، إلخ)**: محرك تنزيل مُجزَّأ خاص بالمشروع (يشبه
  Internet Download Manager) — يفتح حتى 16 اتصالًا متوازيًا لكل ملف عبر HTTP Range requests لزيادة
  السرعة، ويستأنف من نقطة التوقف بدل البدء من الصفر.
- **يوتيوب وأكثر من 1800 موقع آخر**: عبر [yt-dlp](https://github.com/yt-dlp/yt-dlp) (يُنزَّل
  تلقائيًا عند أول استخدام — راجع docs/BUILD.md). يعرض البرنامج **كل الصيغ المتوفرة** لأي رابط
  (دقة الفيديو، الترميز، صوت فقط...) ليختار المستخدم منها، مع اختصارات جاهزة: أفضل جودة (فيديو
  وصوت)، أفضل فيديو فقط، أو استخراج صوت فقط (MP3).

## لماذا يعتمد على yt-dlp بدل استخراج مخصّص؟

مواقع مثل يوتيوب تُغيّر آليات التشفير/الحماية لديها باستمرار؛ إعادة تنفيذ ذلك من الصفر هشّ
وسيتعطّل خلال أسابيع. yt-dlp مشروع مفتوح المصدر نشط جدًا (تحديثات شبه أسبوعية) مخصص لهذه المهمة
بالضبط ويغطي يوتيوب وآلاف المواقع الأخرى بنفس الواجهة. البرنامج يستدعيه كعملية خارجية ويحلّل
مخرجاته، دون نسخ أي كود منه.

## البنية

```
downloader/
├── src/
│   ├── MultiDownloader.Core/   المحرك: التنزيل المُجزَّأ والمُستأنف، إدارة قائمة الانتظار،
│   │                            التكامل مع yt-dlp، الإعدادات — بدون أي واجهة
│   └── MultiDownloader.App/    واجهة WPF (قائمة التنزيلات، إضافة تنزيل، اختيار الصيغة، الإعدادات)
├── build/                       سكربتات PowerShell للبناء
└── docs/                        التوثيق
```

راجع [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) لتفاصيل كيفية عمل الاستئناف والتنزيل المُجزَّأ،
و[`docs/BUILD.md`](docs/BUILD.md) لخطوات البناء الكاملة.

## حالة البناء

طُوِّر هذا المشروع في بيئة Linux بدون .NET SDK أو ويندوز متاحين، لذا **الكود لم يُبنَ أو يُختبر
فعليًا بعد** (نفس الوضع الموثّق بصدق في مشروع Aman في جذر هذا المستودع). راجع
[`docs/BUILD.md`](docs/BUILD.md) للبناء على جهاز ويندوز فعلي، وتوقّع الحاجة لإصلاحات ترجمة طفيفة
محتملة عند أول بناء فعلي لمشروع بهذا الحجم.
